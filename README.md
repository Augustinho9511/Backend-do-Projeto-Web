# 🏆 Mestre das Apostas - Full Stack

O **Mestre das Apostas** é uma plataforma completa de gestão de banca e análise preditiva de futebol. O sistema utiliza Spring Boot para consumir dados em tempo real da **API-Sports**, processando estatísticas de desempenho para oferecer palpites inteligentes.

## 📂 Estrutura do Repositório

* **/backend**: API REST desenvolvida em Java 21 com Spring Boot, Spring Data JPA e WebFlux.
* **/frontend**: Interface SPA desenvolvida em React, Vite e Material UI.

## 🚀 Principais Funcionalidades

* **Análise Preditiva (IA)**: Filtros por data, país e liga com geração de palpites baseados em médias de chutes, faltas e escanteios.
* **Gestão de Apostas**: CRUD completo para registro de odds, valores e controle de status (Green, Red, Cashout).
* **Dashboard Financeiro**: Gráficos de lucro acumulado e ROI para análise de performance.

## 🛠️ Tecnologias

### **Backend**
* Java 21 / Spring Boot 3.
* WebClient (Consumo reativo de APIs externas).
* JPA / Hibernate (Persistência de dados).

### **Frontend**
* React + Vite.
* Material UI (MUI).
* Recharts (Visualização de dados).
